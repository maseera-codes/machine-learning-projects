# Machine Learning Projects

A collection of end-to-end machine learning projects built using Python and scikit-learn.

These projects demonstrate practical skills in data preprocessing, exploratory data analysis, feature engineering, model training, evaluation, and interpretation.

## Projects

### 1. Medical Insurance Cost Prediction

**Type:** Regression

Predicts medical insurance charges based on demographic and health-related features.

**Techniques Used:**
- Exploratory Data Analysis
- Data preprocessing
- One-hot encoding
- Regression models
- Hyperparameter tuning
- Feature importance
- Model evaluation

**Models:**
- Linear Regression
- Ridge Regression
- Lasso Regression
- Decision Tree
- Random Forest
- Gradient Boosting

**Best test R² achieved:** 0.8804

[View Regression Project](./regression/)

---

### 2. Bank Marketing Subscription Prediction

**Type:** Classification

Predicts whether a bank customer will subscribe to a term deposit.

**Techniques Used:**
- Exploratory Data Analysis
- Class imbalance analysis
- Categorical encoding
- Classification models
- Confusion matrix
- Feature importance
- Model comparison

**Models:**
- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting

**Evaluation Metrics:**
- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC

[View Classification Project](./classification/)
